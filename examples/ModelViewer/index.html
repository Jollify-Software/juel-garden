A small box with a hinged lid

This is an ordinary page that scrolls. The model below sits in the middle of the text, on the page's own CSS gradient: the viewer's background is transparent.

Drag the box to turn it; pinch, or hold Ctrl (⌘ on a Mac) and use the mouse wheel, to zoom. The wheel on its own scrolls the page, so the page never gets stuck on the viewer.

The button waits for each animation to end before it can be pressed again, and the lid stays where the animation leaves it.
